# MGestures

MGestures 是一款面向 Windows 的鼠标手势工具，使用 C#、WinForms 和 .NET 8 开发。通过鼠标轨迹、触发角和摩擦边，将常用操作绑定为手势，减少重复点击和键盘操作。

## 主要功能

- 自定义全局手势，以及针对指定应用的独立手势；支持继承全局配置和应用黑名单。
- 支持右键、中键、鼠标 X 键触发，以及可选的 Windows 键触发。
- 可配置斜线手势、轨迹颜色、手势名称显示和超时参数。
- 支持快捷键、按键序列、窗口控制、任务切换、音量调整、打开文件或网址、网页搜索、命令行和 Lua 脚本等操作。
- 支持屏幕触发角、摩擦边、全屏时自动禁用和暂停/继续快捷键。
- 配置自动保存，支持导入、导出 `.mgb` 备份文件。
- 支持通过 GitHub Releases 检查、下载和安装更新，并在更新完成后重新启动。

## 下载与运行

从 [GitHub Releases](https://github.com/JackZ2024/MGestures/releases) 下载已编译的软件包。GitHub 自动生成的 `Source code` 压缩包仅包含源码，不能直接运行。

当前项目面向 Windows x64，目标框架为 `net8.0-windows`。依赖框架的发布包需要安装 **.NET 8 Windows Desktop Runtime（x64）**，仅安装普通 .NET Runtime 不够。

1. 将软件包完整解压到独立目录，不要只复制 `MGestures.exe`。
2. 启动 `MGestures.exe`。当前程序清单要求管理员权限，Windows 会显示 UAC 提示。
3. 右键点击系统托盘图标，选择“设置”，查看和修改手势。
4. 按住已启用的手势键，移动鼠标绘制轨迹，松开按键执行对应操作。

首次使用建议先检查默认手势及“触发角 & 摩擦边”配置；部分默认操作涉及关闭程序或关机，不需要的操作可修改或禁用。

## 用户配置与备份

在设置窗口的菜单中选择“导出...”可以备份配置，默认文件名为 `MG-yyyyMMdd.mgb`；选择“导入...”可以恢复备份，并选择导入设置、手势，以及合并或替换手势。

请只导入可信来源的配置。手势可以执行命令行和 Lua 脚本，导入后应检查相关操作，尤其是在程序以管理员权限运行时。

## 软件更新

启用“自动检查更新”后，软件在每次启动稍后检查一次；Release 构建默认延迟约 30 秒。也可以在设置中点击“立即检查”。

- 有新版本时显示更新提示，由用户选择是否更新。
- “跳过此版本”后，自动检查不再提示该版本，但仍会提示更高版本。
- 手动检查不受“跳过此版本”的限制。
- 确认更新后，程序先下载、校验并准备更新，再退出、替换文件并重新启动。
- 如果 Release 缺少合格的软件包或校验信息，自动更新不可用，可以通过“手动下载”打开发布页面。


## 从源码构建

需要 Windows、.NET 8 SDK，以及安装了“.NET 桌面开发”工作负载的 Visual Studio。项目引用了 Windows COM 组件，构建时应使用 **Visual Studio 自带的 MSBuild**，不要直接使用 `dotnet build`。

### Visual Studio

1. 打开 `MGestures.sln`。
2. 还原 NuGet 依赖，选择 `Release` 配置。
3. 将 `MGestures.App` 设为启动项目并构建。
4. 默认构建输出位于 `MGestures.App/bin/Release/net8.0-windows/`。
